## How To Run

1. Create virtual environment

python -m venv venv

2. Activate virtual environment

Windows:
venv\Scripts\activate

Linux/macOS:
source venv/bin/activate

3. Install requirements

pip install -r reqs.txt

4. Run application

python app.py

5. Open browser

http://127.0.0.1:5000
